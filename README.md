# Generative AI - Lab Assignment 04: Multimodal Prompt-to-Image Generation

## Aim
To generate images from descriptive text prompts using Stable Diffusion, compare prompt variants across different visual styles while keeping random seeds and generation settings constant, and evaluate subject and style adherence.

## Software and Libraries Used
- Python
- Google Colab (GPU Runtime) / Jupyter Notebook
- PyTorch
- Hugging Face Diffusers (Stable Diffusion)
- Hugging Face Transformers
- Matplotlib & PIL

## Repository Contents
- `Lab4.ipynb`: Python Jupyter Notebook demonstrating Stable Diffusion pipeline setup, text prompt conditioning, guidance scale tuning, seed control, and multi-style comparison.
- `Lab 4.docx`: Laboratory record document with diffusion theory (forward and reverse processes, latent diffusion, text conditioning with CLIP), prompt comparisons, output images, and quality evaluation.
